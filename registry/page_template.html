What this run could see

A gate this strict can miss weak lines. We measured how often R1 would catch a real line of a given strength, hidden among 185, on synthetic data. R1 rules out strong monthly lines in these public indices. It does not rule out weak ones.

Registered first

Targets, 34 outside variables, three placebos, each line's direction and lead window, the method and the code were committed on , before any value was downloaded.

Tested once

Each line must beat a baseline that already knows the target's own last three months, the broad economy and the season, on data from 2016 on that played no part in building it.
